# 🌾 Agro AI — Система прогноза урожайности

> ИИ-система прогноза урожайности для агропредприятий Северного Казахстана  
> Разработано в рамках сотрудничества с **AgroMind** — официальным дилером агротехника в Казахстане

---

## 🎯 Проблема

Фермеры Акмолинской и СКО областей планируют сезон «вслепую» — без инструментов прогнозирования урожайности. Это приводит к неоптимальным решениям по закупке удобрений, найму техники и логистике зерна.

## 💡 Решение

**Agro AI** — веб-приложение, которое анализирует агрономические данные с техники агротехника и прогнозирует урожайность на следующий сезон с учётом:

- 🚜 Исторических данных с данные с техники (посев, уборка, обработка почвы)
- 🌦️ Метеоданных NASA POWER (температура, осадки, ГДД за 5 лет)
- 🛰️ NDVI спутниковых снимков (состояние вегетации)
- 🌱 Базы данных сортов (31 сорт, 12 культур)
- 📊 Региональной статистики БНС РК

## 🛠️ Технологии

| Компонент | Технология |
|---|---|
| ML модель | Random Forest (scikit-learn) |
| Данные | данные с техники API, NASA POWER API, Open-Meteo |
| Интерфейс | Streamlit |
| Спутниковые снимки | NDVI PNG (Sentinel-2) |
| Почвенные зоны | Агрохимические данные РК |

## 📊 Результаты модели

- **Данные:** последних лет, более 100 полей, сотни записей, 23 культуры
- **Кросс-валидация:** Leave-One-Year-Out
- **MAE:** ~2.5 т/га (улучшается с каждым новым сезоном)
- **Фичи:** 25 параметров (агрономия + метео + NDVI)

## 🚀 Установка и запуск

